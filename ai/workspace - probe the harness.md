# Probe the harness

**Open when** the map has no witnessed answer about a capability this  
turn needs.

1. Look inside: the working directory, hidden folders, configs, the  
   harness's tools. Find what the harness does: rule files, subagents,  
   skills, prompt templates, hooks, wrapper scripts.
2. Read from inside. Say what could not be established.
3. Read a version in the map as the day it was taken. Probe again: a  
   new tool, an upgraded output, a lost capability.
4. Fix a mechanism's path and name before writing it.
5. Take the harness space as its permanent configuration folder, never  
   a temp one. A mechanism in Temp is a defect.
6. Take a capability with a witness as read. Probe the rest when used;  
   record found or absent.
7. Let a mechanism written now reach no session now. A session outside  
   the repository gets no injected rules.
