# Compile a rule

**Open when** a rule is not yet a mechanism, or its mechanism no  
longer matches it.

1. Compile what routing needs now, before the act. Put the rest in an  
   entry: trigger, consumer, acceptance, `pending`.
2. Keep one mechanism per rule: it names the section and makes it read  
   there. A copy is the defect.
3. Make a mechanism one command with declared arguments and answers,  
   or a named data file. Otherwise `manual`; say what a person does.
4. Change the rule, compile again, never patch. Diff and explain; an  
   unexplained difference stops.
5. Name in the header where truth lives: file, section, entry. Never  
   this text. English mechanisms.
6. Take the harness's space as its durable configuration folder, never  
   a temporary one. Name the folder in the entry; put it there once.
7. Put the generation mark on the harness side only. The repository  
   gets the product: no pointer file, no index, no copy.
8. Keep the check in the harness, not in the clone: a command, and a  
   hook there where the harness has hooks. The clone receives nothing  
   — not even under `.git/`.
